# Web DevKit Plugin for Config Studio 🌐

Официальный плагин **Web DevKit** для [Config Studio](https://github.com/EdvardBaldanov/config-studio).
Превращает Config Studio в полноценную среду разработки веб-страниц и PHP-скриптов.

## 🚀 Возможности

- **Живой Split-Screen предпросмотр**:
  - Мгновенный рендеринг HTML/CSS прямо в боковой панели.
  - Автоматическое обновление предпросмотра при сохранении файла (`Ctrl+S`).
  - Симуляция адаптивных устройств:
    - **Full** (адаптивная ширина 100%)
    - **Desktop** (1280px)
    - **Tablet** (768px)
    - **Mobile** (375px)
- **Встроенный веб-сервер**:
  - Запуск локального PHP сервера (`php -S 0.0.0.0:8085`) в 1 клик прямо из интерфейса редактора.
  - Автоматический fallback на Python HTTP-сервер (`python -m http.server 8085`), если PHP не установлен на хосте.
  - Кнопка быстрого перехода на работающий сервер в новой вкладке браузера.
- **Интеллектуальное автодополнение Monaco**:
  - Сниппеты HTML5 (шаблоны с Tailwind CDN, div, button, form, input, script, style и др.).
  - Автодополнение стандартных PHP функций, сниппетов циклов, try-catch и блоков вывода.
- **Стартовые шаблоны**:
  - Быстрое создание `index.html` и `index.php` в один клик.

## 📦 Установка

В Config Studio откройте **Настройки (⚙️) → Плагины**:
1. Вставьте ссылку на репозиторий:
   ```
   https://github.com/EdvardBaldanov/config-studio-web-devkit
   ```
2. Нажмите **«Установить по URL»**.

Либо скачайте ZIP-архив репозитория и загрузите его через кнопку **«Установить из ZIP»**.

## 🛡️ Требуемые разрешения

- `ui.panels` — отображение кнопки в тулбаре и панели предпросмотра.
- `terminal.exec` — запуск локального веб-сервера (`php` / `python`).
- `network.bind` — открытие порта 8085 для локального предпросмотра.
